# Ship generated citation data committed in the repo (~62 MB)

Status: superseded October 6, 2026 by
[ADR-0008](0008-one-codebase-two-data-packs.md), which keeps the first claim
(generated data committed and shipped) and retires the second (personal use
only). Kept for the reasoning.

`src/citations/data/` (index, sources, 88 book shards, gzipped bundled talks)
is generated by `tools/build-citation-data.js` but committed and shipped with
the extension. Alternatives — querying BYU's Scripture Citation Index live, or
building at install time — were rejected: there is no public SCI API to query,
the BYU DBs are not redistributable as-is and are gitignored, and the citation
feature must work offline from a content script with no server of our own. The
costs accepted: a heavy repo, and regeneration requiring the gitignored DBs in
`source-data/`. This is also part of why the extension is personal-use only
(never the Chrome Web Store).
